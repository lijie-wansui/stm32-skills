# 电力电子系统的外设与安全边界

本章适用于逆变器、整流器、CHB、DAB、CLLC 等功率变换系统。它是外设配置审查规则，不是完整的功率硬件安全设计规范。

## 1. 区分软件控制与硬件保护

至少分清：
- MCU 软件输出控制。
- 定时器 Break/故障输入。
- MCU 内部 COMP/外部比较器（若有）。
- 门极驱动器的 RST/EN/FAULT。
- 功率级硬件过流、过压和欠压保护。
- 驱动电源和隔离电源状态。

硬件快速关断链路不能依赖普通主循环或低优先级通信中断。

## 2. PWM 启动前核对

在讨论启动 PWM 之前，确认：
- 输出引脚复用和极性。
- 定时器通道及互补通道。
- 初始 CCR 和 ARR。
- CCR/ARR preload 状态。
- MOE/通道使能的控制方式。
- Idle State 和关断电平。
- Dead Time。
- Break 输入和故障极性。
- 门极驱动器 RST/EN 状态。
- 母线电压、驱动电源和功率器件安全条件。

不因代码能够调用启动函数就建议直接接入高压母线。

## 3. 故障处理

故障处理应遵循硬件设计和项目定义：
- 故障发生时硬件输出进入预期安全状态。
- 软件读取故障来源并记录。
- 故障原因未查明前，不自动清除或重新使能。
- 不为测试方便屏蔽 Break、COMP、门极驱动器故障或外部保护。
- 不擅自改变故障有效电平、滤波或锁定配置。

## 4. PWM 与 ADC 协同

电力电子控制中，采样时刻必须与开关状态关联：
- 采样点是否避开开关瞬态。
- 传感器/隔离放大器输出是否已稳定。
- ADC 采样时间是否满足前端阻抗要求。
- ADC 转换是否能在控制算法读取前完成。
- DMA 缓冲区是否会被覆盖。
- 控制计算是否能在下一次 PWM 更新前完成。
- 新 CCR 是否在预期更新事件生效。

不要只根据“ADC 已经配置触发”就认定采样与 PWM 同步正确。

## 5. 多单元/多 MCU 系统

对于多个功率单元：
- 明确每个 MCU 的本地 PWM 时基。
- 明确同步信号来自硬件触发还是通信报文。
- 明确各单元启动、复位和失步后的行为。
- 区分“收到命令”“控制变量更新”和“门极输出实际改变”三个时刻。
- 明确通信中断、节点失联和局部故障时的安全策略。
- 不让通信协同逻辑覆盖本地硬件保护。

## 6. 结论边界

可以根据资料审查设计逻辑和指出风险，但不能在没有实测证据时宣称：
- 死区一定足够。
- 驱动输出一定无直通。
- 过流保护一定及时。
- ADC 采样一定准确。
- 多板同步一定满足目标误差。
- 功率级可以安全带母线上电。

这些结论需要实际波形、测量、故障注入或其他适当的硬件验证。
