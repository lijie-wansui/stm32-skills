## 7. 结论

只总结证据支持的结论：
- 已确认的工程目标和硬件信息。
- 工程配置与源码的一致性。
- 已定位的关键芯片资料。
- 后续编码前必须解决的冲突。
- 尚未确认的硬件事实。

推荐使用“已确认 / 工程目标 / 实物已确认 / 待核实 / 存在冲突”标记状态。
