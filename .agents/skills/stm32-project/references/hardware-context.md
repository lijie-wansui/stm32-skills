# 原理图、PCB 与 MCU 资源关联

## 目标

把 MCU 的数据手册/参考手册信息与真实板级设计联系起来。MCU 文档只能说明芯片本身的能力，原理图、PCB 和 BOM 才能说明该能力在当前板卡上如何连接。

## 1. 板级资料清单

按实际可用资料检查：
- 原理图 PDF 或 EDA 原始工程。
- PCB 工程、Gerber、ODB++、IPC-2581 等制造/交换文件。
- BOM 和装配位号。
- PCB 版本、原理图版本和装配版本。
- 接插件定义、线束说明和外部接口说明。
- 外部器件数据手册，例如隔离器、门极驱动器、运放、ADC 前端、收发器和电源芯片。
- 实物照片或测量记录（若用户提供）。

不同文件格式提供的信息不同。图片/PDF 可能缺少网络连通性；BOM 可能没有封装或替代料信息；PCB 可能不包含完整原理图逻辑。明确资料能支持什么结论。

## 2. 建立 MCU 引脚映射

对每个使用到的 MCU 引脚，尽可能关联：

| 信息 | 证据来源 |
| --- | --- |
| MCU 物理引脚号和封装 | 对应 Datasheet |
| GPIO/Alternate Function 能力 | 对应 Datasheet、Reference Manual |
| CubeMX 配置功能 | `.ioc` |
| 实际 GPIO 初始化 | 生成/用户 C 代码 |
| 原理图网络名 | 原理图 |
| 外部连接器/器件引脚 | 原理图、BOM、器件 Datasheet |
| PCB 实际连线 | PCB 工程或制造文件 |

不能仅凭 CubeMX 中选择了某个 AF，就断言该引脚已连接到预期外部器件；也不能仅凭原理图网络名断言固件已经配置对应 GPIO。

## 3. 电力电子控制板重点关注项

如果项目属于逆变器、整流器、DAB、CHB 或其他功率变换系统，优先梳理以下资源，但必须以具体 MCU 和板级资料为依据。

### PWM 与定时器
- 目标定时器实例、通道和引脚复用。
- 是否具有互补输出、死区插入、Break/故障输入和重复计数器等所需功能。
- 主从定时器同步、触发输出和更新事件。
- PWM 极性、空闲状态、输出使能和实际门极驱动连接。
- 时钟树、计数模式、预分频和周期配置。

不要根据系列惯例推断某个型号具有 HRTIM、特定高级定时器或所需通道；先核对完整型号、封装和 Reference Manual。

### ADC 与采样链
- ADC 实例、通道和对应封装引脚。
- Regular/Injected 等转换组及触发源（按芯片支持情况）。
- 采样时间、分辨率、过采样和校准能力。
- DMA 请求映射、数据宽度和缓冲区组织。
- 定时器触发与 PWM 相位的关系。
- MCU ADC 引脚之前的分压、运放、隔离放大器、滤波和保护电路。

MCU 数据手册的 ADC 指标不能直接代表整条采样链的精度、带宽或延迟。

### 故障与保护链
- 外部比较器、MCU COMP（若有）、定时器 Break 输入和门极驱动器故障输出。
- 故障信号的有效极性、默认状态、上拉/下拉和隔离路径。
- 硬件关断路径是否独立于 CPU 执行。
- 固件如何读取故障、锁存状态和恢复条件。

只做资料梳理，不建议为了软件调试而绕过硬件保护或强制输出 PWM。

### 通信与同步
- CAN/bxCAN/FDCAN、UART、SPI、I2C 等实际实例。
- 收发器/隔离器、连接器和终端电阻。
- 逻辑电平、隔离侧供电和信号方向。
- 多板同步信号、触发输入和通信链路的实际网络连接。
- 固件中断和 DMA 配置是否与硬件连接相符。

## 4. 外部器件资料

涉及外部器件时：
- 先从 BOM 和原理图确认器件完整型号。
- 查该器件制造商官方 Datasheet。
- 核对供电、输入/输出范围、逻辑极性、时序和绝对最大额定值。
- 确认是否存在替代料或不同后缀版本。
- 不用同系列相似型号的数据手册代替。

## 5. 输出形式

适合使用引脚映射表、外设资源表和信号链描述。对每条信号注明证据来自：
- MCU Datasheet/Reference Manual。
- `.ioc` 或源代码。
- 原理图。
- PCB。
- BOM/外部器件 Datasheet。
- 用户提供的实测信息。

如果资料缺失，写出“尚未由原理图/PCB确认”，不要仅凭命名推断电路功能。
